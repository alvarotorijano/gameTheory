# My Agent from Guillermo Zapata

To try and beat a one on one just by returning DEFEAT the agent would always win. When trying to achieve the highest amount of points against the current 3 other agents, going tit for tat is the most likely strategy to score the most points over all. However there would always be a tie against a Copycat agent. 

When playing against the second chance agent, Copycat would lose to it in the overall point system when paired up against the Random agent.

The idea is to mix the second chance agent with the copycat agent, trying to achieve the best of both worlds.
